How to view and save custom levels for Lode Runner


This utility is for this web version: https://robthelinuxguy.github.io/LodeRunner/

Your custom levels are saved in your browser local storage. You can extract them. This guide is only for Chrome.

Use this link to help you view your levels: Here
Make sure you are on the correct game URL. You will see "key" and "value" pairs for your levels ("loderunner_userLevelXXX")

Want to add a new level? Just add the new level values here: https://github.com/robthelinuxguy/LodeRunner/issues
